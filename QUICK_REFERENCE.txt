🔑 REQUIRED CREDENTIALS (Before Going Live)

Edit: backend/.env

MongoDB:
  MONGO_URI=mongodb://localhost:27017/eldercare
  # or MongoDB Atlas: mongodb+srv://user:pass@...

Firebase (FCM Push Notifications):
  FIREBASE_PROJECT_ID=your-project-id
  FIREBASE_PRIVATE_KEY=your_private_key
  FIREBASE_CLIENT_EMAIL=your-email@...

Twilio (SMS Alerts):
  TWILIO_ACCOUNT_SID=your_sid
  TWILIO_AUTH_TOKEN=your_token
  TWILIO_PHONE_NUMBER=+1234567890

JWT (Authentication):
  JWT_SECRET=your_32_char_secret_key_here

🆘 COMMON ISSUES

Backend won't start?
→ Check MongoDB: mongo mongodb://localhost:27017
→ Check .env: cat backend/.env
→ Check port: lsof -i :5000

Frontend can't connect?
→ Backend running? curl http://localhost:5000/health
→ Check CORS in backend/.env
→ Clear browser cache

Notifications not working?
→ Firebase credentials correct?
→ VAPID key in .env?
→ Browser notifications enabled?

See full troubleshooting: COMPLETE_IMPLEMENTATION.md
